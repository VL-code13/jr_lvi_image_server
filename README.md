Веб‑приложение для загрузки и хранения изображений с получением прямых ссылок на них.


## Описание


Сервис позволяет пользователям загружать изображения в форматах JPG, PNG и GIF, получать прямые ссылки на них и использовать эти ссылки в соцсетях, блогах или для отправки друзьям.

**Ключевые особенности:**
* быстрая загрузка изображений (до 5 МБ);
* прямые ссылки для удобного обмена;
* надёжное хранение файлов;
* детальное логирование действий;
* лёгкое развёртывание через Docker Compose.

## Технологии


* **Бэкенд:** Python 3.12+;
* **Веб‑сервер:** Nginx;
* **Контейнеризация:** Docker и Docker Compose;
* **Библиотеки Python:** `Pillow` (для работы с изображениями), стандартная библиотека для обработки запросов (`http.server`) и логирования (`logging`);
* **Хранение данных:** Docker Volumes для изображений и логов.

## Функциональность


### Основные маршруты

* **`/`** — главная страница с приветственным сообщением и ссылками на основные функции;
* **`/upload`** (`POST`) — загрузка изображений:
    * поддержка форматов: `.jpg`, `.png`, `.gif`;
    * ограничение размера: до 5 МБ;
    * генерация уникального имени файла;
    * сохранение в папку `/images` при успешной проверке;
    * возврат уникальной ссылки пользователю;
* **`/images/<имя_файла>`** — доступ к загруженным изображениям (обслуживается Nginx).

### Пользовательские сценарии


1. **Загрузка изображения:**
    * переход на `/upload`;
    * загрузка файла через HTTP‑запрос;
    * проверка формата и размера бэкендом;
    * сохранение в папку `/images` при успешной проверке;
    * возврат уникальной ссылки пользователю.
2. **Просмотр изображений:**
    * запрос по ссылке `/images/<имя_файла>`;
    * получение изображения от Nginx для просмотра или скачивания.

## Архитектура

Система состоит из двух основных компонентов:

1. **Python‑бэкенд** (порт 3000):
    * обработка HTTP‑запросов;
    * валидация загружаемых файлов;
    * сохранение изображений в папку `/images`;
    * логирование действий в файл `app.log`.
2. **Nginx‑сервер** (порт 8080):
    * раздача статических файлов и загруженных изображений по маршруту `/images/`;
    * проксирование запросов на Python‑бэкенд для других маршрутов.

Компоненты взаимодействуют через локальную сеть, созданную с помощью Docker Compose.
